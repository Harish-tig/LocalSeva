Platform Capabilities

Two integrated modules providing comprehensive service booking and marketplace functionality

01

Service Booking Module

Complete workflow management from booking creation to service completion. Providers submit quotes, customers accept offers, and both parties track real-time status updates throughout the service lifecycle.

02

Marketplace Module

Peer-to-peer product listings with category management, condition tracking, and buyer-seller communication. Direct contact exchange and comment system facilitate transparent transactions.

03

Authentication & Security

Stateless JWT token authentication with role-based access control (User, Service Provider, Seller). Includes SHA-256 OTP hashing for password recovery, secure password validation, and strict 3/min scoped rate limiting on all auth endpoints.

04

Performance & Safety

Accelerated with Redis caching (60s provider list, 5min marketplace list) with automatic PostgreSQL fallback. Mumbai Western Line station validation (29 corridor stations) guarantees regional accuracy, paired with an integrated user reporting and admin review system.

Application Architecture

Decoupled multi-tier cloud infrastructure engineered for resilience, low latency, and strict security

🔍 Click diagram to enlarge
Client Tier
Decoupled Frontend

Standalone HTML5, CSS3 & Vanilla JavaScript client hosted on Render, CDN, or static host.

  • Cross-Domain HTTP API communication
  • Configurable CORS origins via .env
  • JWT Bearer token storage in LocalStorage
  • Zero-build runtime API URL switching
API Engine
Django DRF Backend (AWS EC2)

Stateless REST API hosted on AWS EC2 running Django 4.2 & Django REST Framework 3.14.

  • DRF Scoped Rate Limiter (3 req/min on auth)
  • SimpleJWT token issuance & verification
  • OTP hashing & verification logic
  • Built-in Django Admin moderation panel
Data Tier
PostgreSQL & Redis (Render)

Managed data persistence and high-speed in-memory caching hosted on Render services.

  • PostgreSQL storing relational app data
  • Redis in-memory caching for queries
  • Hashed OTP verification storage
  • Automatic database query fallback on cache miss
Cloud Services
Media & SMTP Mail

Offloaded media delivery and transactional email handling for user verification.

  • Cloudinary cloud storage for avatars & photos
  • SMTP Mail Service for password reset OTP
  • TLS encrypted email delivery
  • Preserves backend compute bandwidth

Local Development & Docker Deployment

Reproducible, isolated multi-container orchestration powered by Docker Compose and bridge networking

🔍 Click diagram to enlarge
Network
Bridge Network (localseva-net)

Isolated user-defined Docker bridge network facilitating fast inter-container DNS discovery.

  • Inter-service DNS resolution by container name
  • Isolation from host network clutter
  • External network declaration prevents teardown
  • Cross-origin ingress from any frontend origin
Services
Containerized Stack

Three coordinated microservices running seamlessly in dedicated Linux containers.

  • backend (Port 8000): Python 3 / Django WSGI API
  • redis (Port 6379): Redis 8.10 cache server
  • postgres (Port 5432): PostgreSQL 16 database
  • Independent standalone compose configs available
Persistence
Named Volumes & Storage

Guaranteed relational data persistence across container rebuilds and host restarts.

  • Volume: localseva_postgres_data
  • Mounted at /var/lib/postgresql/data
  • Declared external for disaster recovery
  • Zero database loss during container updates

Required Fields

email string, valid email, unique Required
password string, min 8 chars Required
password2 string, must match password Required
